# مجموعه تجاری فاضل

سایت رسمی مجموعه تجاری فاضل در نجف‌آباد – طراحی شده با HTML, CSS و JavaScript خالص.

## ویژگی‌ها

- طراحی نئونی و شیشه‌ای مدرن
- اسلایدر اختصاصی در بالای تمام صفحات
- صفحات جداگانه برای: اصلی، درباره ما، خدمات، طبقات، دکان‌ها
- صفحات اختصاصی برای ۳ دکان: کاربیست، کافی‌نت پارک، رستوران دکتر مصدق
- بهینه برای موبایل و دسکتاپ
- سئو و دسترسی‌پذیری
